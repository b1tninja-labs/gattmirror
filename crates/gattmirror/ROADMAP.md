# gattmirror roadmap

The binary and its library: a `Backend` trait for the real-adapter side, a profile-to-attribute-database builder,
relay glue over `att-server`, a `serial` shim that serves a serial profile from any `serial-stream::ByteStream`, a simulated adapter (`sim`, a test dummy) and a CLI. It is transport only: it parses no
OBD, ELM327 or UDS, and the `sim` module's canned `AT` replies exist to exercise the relay, not to mirror anything.

Core Specification 7.0 is imported. The HCI and ATT sections read on 2026-11-21 are in
`crates/hci-wire/ROADMAP.md` and `crates/att-server/ROADMAP.md`. Advertising-data type identifiers and the Flags
bit field stay unread. `[ok]` here is this crate's own bookkeeping, each broken once (the code changed, the named
test watched to fail, the change reverted). Anchor "none" means no standard defines it.
