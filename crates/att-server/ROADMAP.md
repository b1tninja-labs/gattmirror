# att-server roadmap

An ATT PDU codec, a GATT attribute table and a per-connection server, with no I/O. This crate was first written
without the Bluetooth Core Specification and then re-anchored to it: every row below was checked against Core 6.3
(`core-specification-6-3` in the `primarysource` `bluetooth` collection, status final, dated 2026-03) with the
`bluetooth_*` tools. Break notes say what was changed to make the named test fail.

Anchors. `F` is Bluetooth Core Specification 6.3 Vol 3 Part F (ATT) and `G` is Vol 3 Part G (GATT); the number is the
section the tool's `cite` gives, whose string reads "Bluetooth Core Specification 6.3 <section sign><n>" (the Part is not in the
tool's string, so it is added here). `Table 3.43` is the valid-error table of Part F section 3.4.9. A row
anchored to a section that the spec leaves open says so and stays `[open]`. Reference-implementation comparisons
(Bumble, Android) are kept where they explain a choice; they are not normative.
