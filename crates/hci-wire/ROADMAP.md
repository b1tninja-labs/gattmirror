# hci-wire roadmap

H4 framing and a typed view of the HCI packets `gattmirror` exchanges with the emulator's virtual controller.
The sections named below were read from Core Specification 7.0 (`bluetooth:core-specification-7-0`) on
2026-11-21. The Core Specification Supplement, Part A, and Assigned Numbers are not imported.
Advertising-data type identifiers and the Flags bit field are not in this crate and stay unread.
Break notes say what was changed to make the named test fail.
