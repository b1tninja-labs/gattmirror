# hci-wire roadmap

H4 framing and a typed view of the HCI packets `gattmirror` exchanges with the emulator's virtual controller.

Anchors were re-read on 2026-11-15 against **Bluetooth Core Specification 6.3** (final, 2026-03; `bluetooth_*`
tools, doc id `core-specification-6-3`). Version 6.0 in the same corpus is marked withdrawn, so 6.3 is the
reference. Cite strings are of the form `Bluetooth Core Specification 6.3 §7.8.5`; all sections are Vol 4 Part E
unless stated. The corpus index mislabels some section ids (a read of `§5.4.2` returned a Vol 3 Part H section), so
sections were located by line range and the printed headings are what is cited. Break notes say what was changed to
make the named test fail, then reverted.
