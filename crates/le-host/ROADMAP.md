# le-host roadmap

The LE peripheral host over `hci-wire`. This slice: controller init and advertising (gate E1), and one ATT connection at a time (E2/E3 transport). No Bluetooth specification text was available, so every anchor is a live
observation or `[unread]`. "Broken by" says what was changed to make the named test fail, then reverted.
