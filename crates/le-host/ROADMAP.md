# le-host roadmap

The LE peripheral host over `hci-wire`. This slice: controller init and advertising (gate E1), and one ATT connection at a time (E2/E3 transport).
Anchors were re-read on 2026-11-15 against **Bluetooth Core Specification 6.3** (final, 2026-03; doc id `core-specification-6-3` in the `bluetooth_*` tools; 6.0 in the same corpus is withdrawn). Cites read `Bluetooth Core Specification 6.3 §x`; HCI sections are Vol 4 Part E. The corpus index mislabels some section ids, so sections were located by line range and the printed headings are cited. The Core Specification Supplement and Assigned Numbers are not in the corpus, so AD type numbers stay `[unread]`. "Broken by" says what was changed to make the named test fail, then reverted.
